# templates

Personal collection of starter templates. Each stack lives in its own folder with its own README — grab one, clone, `.env`, build.

## Available

| Template | Stack | Status |
|---|---|---|
| [`sveltekit/`](sveltekit/README.md) | SvelteKit + TailwindCSS v4, auth-ready SaaS starter | scaffold done, auth/DB in progress |

## Planned

- `nextjs/` — Next.js SaaS starter

## Convention

Each template folder is self-contained (own `package.json`, own `README.md` with stack details, setup, and roadmap). Root README stays an index only.
